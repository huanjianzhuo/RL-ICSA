## 📊 Datasets

Our benchmark framework supports three standard computer vision datasets commonly used in Federated Learning research:

1. **MNIST**
   * **Description**: Handwritten digit classification dataset (10 classes, grayscale $28 \times 28$).
   * **Official Page**: [Yann LeCun's MNIST Database](http://yann.lecun.com/exdb/mnist/)

2. **CIFAR-10**
   * **Description**: 60,000 $32 \times 32$ color images in 10 object classes (50,000 training, 10,000 test).
   * **Official Page**: [CIFAR-10 Dataset by Alex Krizhevsky](https://www.cs.toronto.edu/~kriz/cifar.html)

3. **CIFAR-100**
   * **Description**: Similar to CIFAR-10, but with 100 fine-grained classes grouped into 20 superclasses.
   * **Official Page**: [CIFAR-100 Dataset by Alex Krizhevsky](https://www.cs.toronto.edu/~kriz/cifar.html)
